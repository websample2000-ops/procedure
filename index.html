Webサイト管理・共同作業用 アカウント準備マニュアル

Webサイトの構築・デプロイ・更新保守に必要な各クラウドサービスの設定手順です。すべて無料プランの範囲で運用可能です。作業完了後に作業者の権限を解除する手順も記載しています。

インフラ・ホスティング

1. Cloudflare

① アカウント作成手順

  1. Cloudflare 登録ページ を開きます。
  2. メールアドレス と パスワード（8文字以上、大文字・数字・記号を含む）を入力し、
    「Sign in」をクリックします。
  3. 登録メールアドレス宛に届く確認メール内の認証リンクをクリックし、アドレス確認を完了します。
※メールアドレスの認証を行わないと、メンバー招待機能が利用できません。

② 作業アカウントの招待と権限設定（Administrator）

  1. Cloudflare ダッシュボード にログインします。
  2. 左側メニューの 「管理（Manage Account）」 → 「メンバー（Members）」 を開きます。
  3. 「メンバーを招待（Invite members）」 をクリックします。
  4. 作業者のメールアドレスを入力します。
  5. ロール（権限）の選択で 「管理者（Administrator）」 を選択します。
    ※作業者がPagesの新規デプロイ、Workers・D1データベースの作成をゼロから代行できるようにするため、必ず「Administrator」を指定してください。（クレジットカード情報やプラン変更権限は所有者にしか無いため、勝手に課金される心配はありません）
  6. 「招待を送信」 をクリックします。

【納品・作業完了後】作業アカウントの削除手順

  1. ダッシュボード左側メニュー 「管理（Manage Account）」 → 「メンバー（Members）」 を開きます。
  2. メンバー一覧から作業者のメールアドレスを探し、右端にある 「編集（Edit）」 またはメニューアイコンをクリックします。
  3. 「メンバーを削除（Remove）」 をクリックして確認モーダルで承認すると、作業者のアクセス権が即座に解除されます。
ソースコード管理・Pages

2. GitHub / GitHub Pages

① アカウント作成手順

  1. GitHub 公式登録ページ を開きます。
  2. 画面の指示に従い、メールアドレス、パスワード、ユーザー名（英数字） を入力します。
  3. 届いたメール記載の8桁の認証コードを入力してアカウント作成を完了します。

② 空リポジトリの作成手順

  1. GitHub右上の「＋」アイコン → 「New repository」 をクリックします。
  2. Repository name（リポジトリ名）に任意の名前（例: official-site）を入力します。
  3. 公開設定で 「Public」（またはPrivate）を選択します。
  4. ファイル（READMEや.gitignore）の初期化チェックはすべて空のままにし、最下部の 「Create repository」 をクリックします。

③ 作業アカウントの招待と権限設定（Admin）

  1. 作成したリポジトリ画面上部のタブから 「Settings（設定）」（歯車マーク）を開きます。
  2. 左側メニュー「Access」配下の 「Collaborators」 を選択します（パスワード再確認が出た場合は入力します）。
  3. 「Add people」 をクリックし、作業者の GitHubユーザー名 または メールアドレス を検索して追加します。
  4. 追加された作業者の権限（Role）を Write から Admin（管理者） に変更します。
    ※GitHub Pagesの有効化、ビルドトリガー、環境変数設定など、公開に必要な内部設定をすべて代行するために「Admin」権限が必要です。（リポジトリ自体の完全削除権限は所有者本人のみに限定されています）

【納品・作業完了後】作業アカウントの削除手順

  1. 該当リポジトリの 「Settings（設定）」 → 「Collaborators」 を開きます。
  2. 一覧に表示されている作業者の名前の右側にあるゴミ箱アイコン（「Remove」）をクリックします。
  3. 確認ポップアップで削除を実行すると、作業者はリポジトリの編集・閲覧ができなくなります。
認証・セキュリティ

3. Firebase（Google認証）

① プロジェクト作成手順

  1. Googleアカウントにログインした状態で Firebase Console にアクセスします。
  2. 「プロジェクトを追加」 を選択し、任意のプロジェクト名を入力して「続行」を押します。
  3. Google アナリティクス設定画面が出た場合は「無効（または有効）」を選択し、「プロジェクトを作成」 をクリックします。

② Google認証の有効化手順

  1. ダッシュボード左メニューの 「構築（Build）」 → 「Authentication」 を選択し、「始める」を押します。
  2. 「ログイン プロバイダ」一覧から 「Google」 を選択します。
  3. 右上の 「有効にする」 をオンにし、プロジェクトのサポートメールでご自身のメールアドレスを選択して 「保存」 をクリックします。

③ 承認済みドメインの追加

  1. Authentication画面上部の 「設定（Settings）」 タブ → 「承認済みドメイン」 を開きます。
  2. 「ドメインを追加」 を押し、公開先のドメイン（例：〇〇.pages.dev など）を入力して保存します。

④ 作業アカウントの招待と権限設定（Editor）

  1. 画面左上の歯車マーク（プロジェクト設定）→ 「ユーザーと権限」 を開きます。
  2. 「メンバーを追加」 をクリックします。
  3. 作業者の Google メールアドレスを入力し、ロールに 「編集者（Editor）」 を選択して「追加」をクリックします。

【納品・作業完了後】作業アカウントの削除手順

  1. Firebase画面左上の歯車マーク → 「ユーザーと権限」 を開きます。
  2. メンバー一覧から作業者のアドレス右側にあるメニュー（縦の3点リーダー）をクリックし、「アクセス権を削除」 を選択します。
  3. 確認画面で削除を実行すると、権限が解除されます。
