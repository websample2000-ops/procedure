Webサイト管理・共同作業用 アカウント準備マニュアル

Webサイトの構築・デプロイ・更新保守に必要な各クラウドサービスの設定手順です。すべて無料プランの範囲で運用可能です。作業完了後に作業者の権限を解除する手順も記載しています。

インフラ・ホスティング

1. Cloudflare

① アカウント作成手順

  1. Cloudflare 登録ページ を開きます。
  2. Continue with Google を選択し、サインアップするGoogleアカウントを選択します。

  3. Googleでログイン の次へを選択します。

  4. 下記のダッシュボード画面が表示されれば登録完了です。

② 作業アカウントの招待と権限設定（Administrator）

  1. Cloudflare ダッシュボード にログインします。
  2. 左側メニューの 「管理（Manage Account）」 → 「メンバー（Members）」 を開きます。

  3. 「メンバーを招待（Invite members）」 をクリックします。

  4. ロール（Overall roles）の選択で 「管理者（Administrator）」 を選択します。
  5. 画面を一番下までスクロールし、「Create policy」 をクリックします。

  6. + Add permission policy をクリックします。

  7. Add email addresses に作業者のメールアドレスを入力します。
    8. 招待アドレス：urukanero.works@gmail.com
  8. ロール（Overall roles）の選択で 「管理者（Administrator）」 を選択します。
    ※作業者がPagesの新規デプロイ、Workers・D1データベースの作成をゼロから代行できるようにするため、必ず「Administrator」を指定してください。（クレジットカード情報やプラン変更権限は所有者にしか無いため、勝手に課金される心配はありません）
  9. 画面を一番下までスクロールし、「Invite members」 をクリックします。
    10. ※招待完了後、ご連絡いただけると幸いです。

【納品・作業完了後】作業アカウントの削除手順

  1. ダッシュボード左側メニュー 「管理（Manage Account）」 → 「メンバー（Members）」 を開きます。
  2. メンバー一覧から作業者のメールアドレスを探し、右端にある 「･･･」 をクリックします。
  3. 「Remove member」 をクリックして確認モーダルで承認すると、作業者のアクセス権が即座に解除されます。
ソースコード管理・Pages

2. GitHub / GitHub Pages

① アカウント作成手順

  1. GitHub 公式登録ページ を開きます。
  2. Continue with Google を選択し、サインアップするGoogleアカウントを選択します。

② 空リポジトリの作成手順

  1. 画面左側にある「Create repository」
    または、GitHub右上の「＋」アイコン → 「New repository」 をクリックします。

  2. Repository name（リポジトリ名）に任意の名前（例: official-site）を入力します。
    3. ※リポジトリ名は公開されないので任意の名前で問題ありません。
    ※URL名になるのはCloudflareのリポジトリ名になります。
  3. 公開設定で 「Private」を選択します。
    4. ※「Public」で設定してしまっても、後で「Private」に変更可能です。
  4. ファイル（READMEや.gitignore）の初期化チェックはすべてデフォルトのままにし、最下部の 「Create repository」 をクリックします。

③ 作業アカウントの招待

  1. 作成したリポジトリ画面上部のタブから 「Settings（設定）」（歯車マーク）を開きます。

  2. 左側メニュー「Access」配下の 「Collaborators」 を選択します（パスワード再確認が出た場合は入力します）。

  3. 「Add people」 をクリックし、作業者の メールアドレス を入力し、「Add [入力したメールアドレス]」をクリックします。
    4. 招待アドレス：urukanero.works@gmail.com
    ※招待完了後、ご連絡いただけると幸いです。

【納品・作業完了後】作業アカウントの削除手順

  1. 該当リポジトリの 「Settings（設定）」 → 「Collaborators」 を開きます。
  2. 一覧に表示されている作業者の名前の右側にあるゴミ箱アイコンをクリックします。
  3. 確認ポップアップで「Remove [アカウント名] from this repository」をクリックで削除できます。

3. Firebase（Google認証）

① プロジェクト作成手順

  1. Googleアカウントにログインした状態で Firebase Console にアクセスします。
  2. 「Firebase プロジェクトを設定して開始」 を選択します。

  3. 任意のプロジェクト名を入力し、「Firebase の規約に同意します」にチェックをいれて「続行」を押します。

  4. 続けて表示される「Firebase プロジェクトのAIアシスタンス」は何もいじらずに「続行」を押します。

  5. Google アナリティクス設定画面が出た場合は「無効（または有効）」を選択し、「プロジェクトを作成」 をクリックします。
    6. ※アナリティクスの有効/無効はお好きな方を選んでください。
    ※設定には影響しません。

② Google認証の有効化手順

  1. ダッシュボード左メニューの 「プロジェクトの概要」 から 「+アプリを追加」 を選択します。

  2. 表示されるプラットフォームメニューから 「 (ウェブ)」 を選択します。

  3. 「アプリのニックネーム」 に任意のニックネームを入力し 「アプリを登録」 を選択します。

  4. 表示される 「SDK」 をコピペしてメモ帳などに保存し 「コンソールに進む」 を選択してください。
    ※後ほど共有ください。認証システム実装時に使用します。
    5. SDKは下記内容のコードになります。
    ---------

    // Import the functions you need from the SDKs you need
    import { initializeApp } from "パス";
    // TODO: Add SDKs for Firebase products that you want to use
    // https://firebase.google.com/docs/web/setup#available-libraries

    // Your web app's Firebase configuration
    const firebaseConfig = {
    apiKey: "APIキー",
    authDomain: "ドメイン",
    projectId: "プロジェクトID",
    storageBucket: "ストレージバケット",
    messagingSenderId: "メッセージング センダーID",
    appId: "アプリID"
    };

    // Initialize Firebase
    const app = "アプリ";
    基本的には他人に知られてもシステム上のセキュリティ問題は発生しない（公開前提の）ものです。
    ただし、不要なトラブルを防ぐためにも、掲示板やSNS、ブログなどのパブリックな場所に故意に文字列を書き込んだり、スクリーンショットを公開したりすることは控えていただきますようお願いいたします。

③ 承認済みドメインの追加

※この手順は私がサイトのドメイン作成後、ドメインをお伝えするのでそのタイミングで行ってください。
  1. 「セキュリティ」 → 「Authentication」 を選択します。

  2. 「始める」 を選択します。（表示されない場合はこの手順はスキップで大丈夫です）

  3. 「ログイン方法」 のタブを選択し、追加のプロバイダから 「Google」 を選択します。

  4. 「有効にする」 をONにし、「プロジェクトのサポートメール」ご自身のメールアドレスを入力して 「保存」 します。

  5. 今度は 「設定」 タブを選択し、「承認済みドメイン」 を選択します。

  6. 「ドメインの追加」 を選択し、表示されるダイアログにGoogle認証を使用する 「ドメイン」 を入力し、「追加」 します。
